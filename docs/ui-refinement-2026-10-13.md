# Helios UI 优化记录

优化范围：管理端全局布局、仪表盘、登录、项目列表，以及账户/项目共享搜索。沿用黑白主题与 Helios 太阳标识。未提交或部署。

- 全局布局统一标题、面包屑、当前导航、移动抽屉、跳转到内容入口；BasicPage 避免嵌套 main。
- 仪表盘统一统计与面板间距，减少重复卡片留白，使用 use-latest-query 与持久失败重试。
- 登录支持原生表单提交、IME 防重复触发、内联错误、正确自动填充与密码显隐。
- 项目名称改为可键盘操作的链接，补全操作名称，支持项目标识搜索及无结果恢复。
- 搜索复用 SearchInput，清除立即生效并恢复输入焦点。主题选项中文化。
- SelectContent 使用 trigger-width popper；70px 分页触发器和弹层实测同宽。全局支持 reduced-motion、forced-colors 滚动条。
